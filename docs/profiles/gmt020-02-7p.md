# GMT020-02-7P

## Summary

ESP32-WROOM-32 profile for a 2.0-inch GMT020-02-7P ST7789 display.

The native 240×320 portrait panel is used as a 320×240 landscape display.

## Selection

```text
ST7789 240x320 - GMT020-02-7P
```

```c
CONFIG_USER_DISPLAY_ST7789_GMT020
```

## Display

| Setting | Value |
|---|---|
| Intended target | ESP32 |
| Controller | ST7789 |
| Native resolution | 240×320 |
| Runtime orientation | 320×240 landscape |
| Interface | SPI |
| SPI frequency | 40 MHz |
| SPI read frequency | 20 MHz |
| Colour order | BGR |
| Touch | None |
| Software backlight control | None |

## Display wiring

| Signal | GPIO |
|---|---:|
| SCLK | 32 |
| MOSI | 33 |
| MISO | Not used |
| RST | 25 |
| DC | 26 |
| CS | 27 |

These control pins avoid the original ESP32 boot-strapping pins and allow the display to remain connected during UART flashing.

## Sensor defaults

| Setting | Value |
|---|---:|
| SEN54 I²C port | 0 |
| SEN54 SDA | GPIO13 |
| SEN54 SCL | GPIO14 |
| DS18B20 | Disabled |

## Notes

- The display backlight is powered directly; no `TFT_BL` GPIO is defined.
- Run a full clean build after changing TFT_eSPI pins or display settings.
- If the display is unstable at 40 MHz, test 27 MHz or 20 MHz.
